# App Store Submission Draft

## App Name
IdleFolder

## Subtitle
안 쓰는 앱 정리 도우미

## Promo Text
30일 이상 안 쓴 앱을 찾아 한 번에 정리하세요.

## Keywords
앱정리,홈화면,디지털정리,생산성,저장공간,오프로드,리마인더

## Description
IdleFolder는 오랫동안 사용하지 않은 앱을 찾아 정리 대상 리스트를 만들어 줍니다.

홈 화면 아이콘 이동은 사용자가 직접 진행하고, 앱은 체크리스트 방식의 정리 세션을 제공합니다.

앱 제거/오프로드/홈 화면에서 제거를 빠르게 결정할 수 있도록 단계별 가이드를 제공합니다.

사용 데이터는 가능한 한 기기 내에서 처리합니다.

## Review Notes
- IdleFolder는 iOS 홈 화면 아이콘을 자동 이동하지 않습니다.
- 사용자가 직접 이동하도록 체크리스트 기반 정리 세션을 제공합니다.
- 사용량 권한은 선택 사항이며, 미허용 시 수동 모드로 핵심 기능을 사용할 수 있습니다.
- 데이터는 기본적으로 온디바이스 처리합니다.

## Privacy Summary
- 수집 항목: 정리 설정, 예외 목록, 정리 세션 기록
- 선택 항목: 앱 사용량 요약(권한 허용 시)
- 처리 방식: 온디바이스 우선, 외부 전송 기본 비활성
- 제어: 사용자가 권한 철회 및 로컬 데이터 삭제 가능
